# 💼 Portfolio — Mohammed Sharuk M S

My personal portfolio site, built with **React**, **TypeScript**, **Vite** and **Tailwind CSS**, with a light/dark theme.

## Sections
- **Hero** and **About**: who I am and what I do
- **Skills**: the tools and technologies I work with
- **Projects**: things I've built
- **Contact**: how to reach me

## Tech
React · TypeScript · Vite · Tailwind CSS · lucide-react icons

## Run locally
```bash
npm install
npm run dev
```
